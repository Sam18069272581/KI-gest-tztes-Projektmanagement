# 04 · Demonstrator

Der Prototyp unterstützt die Methode: gleiche Oberfläche, zwei Bedingungen, zwei Fälle, gemeinsames Zeitlimit je Runde, protokollierte KI-Assistenz und unabhängige Bewertung. Er ist ein lokales Forschungswerkzeug, keine vollständige PM-Plattform.

| Dokument | Inhalt |
|---|---|
| [Schnellstart](quickstart.md) | Python starten und echten Modellzugang konfigurieren |
| [Betrieb und Daten](operations.md) | Freeze, Einladungen, Export und Analyse |
| [Verifikation](verification.md) | Automatisierte Belege und offene Live-/Browserprüfungen |

**Bekannte Grenzen:** kein API-Key im Arbeitskontext, daher noch kein bestätigter echter KI-Erfolg; vollständige neue UI-Sequenzprüfung nach den letzten Änderungen ausstehend. Private formale Fallquelle noch umzusetzen. Bis diese Punkte geprüft sind, Pilot verwenden und nicht als formal einsatzbereit bezeichnen.

Quellcode bleibt zum einfachen Start im Repository-Hauptverzeichnis. Dokumentenorganisation erfordert kein unnötiges Umbauen der Anwendung.

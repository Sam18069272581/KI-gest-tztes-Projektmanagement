# Pilot und Freigabe vor M2

2–3 Personen außerhalb der formalen Stichprobe. Teammitglieder dürfen pilotieren, formale Personen dürfen die finalen Aufgaben nicht vorher üben. Mindestens ein echter Modellaufruf mit dem gewählten Snapshot. Diese Checkliste ist noch nicht als erledigt markiert.

## Inhalt und Methode

- [ ] Aufgabenstellung/Abgabeanforderungen ohne Zusatzwissen verständlich.
- [ ] Private formale Fälle unterscheiden sich von öffentlichen Demonstrationsfällen.
- [ ] A/B vergleichbar in Leselast, Abhängigkeiten, Ressourcen und Konflikten; keine Gleichwertigkeit allein aus 2–3 Tests behaupten.
- [ ] Basisplan wird vor Offenlegung der Änderungs-/Referenzmaterialien gesperrt.
- [ ] Beide Aufgaben innerhalb 25 Minuten grundsätzlich bearbeitbar; Deadlinefälle werden sauber erfasst.
- [ ] Rubrik an zwei Beispielantworten mit zwei Ratern kalibriert, Referenzentscheidungen fachlich überprüft.
- [ ] Vier Sequenzen und Rekrutierungsplan realistisch; Erfahrung/Zuteilung dokumentiert.

## Technik

- [ ] Manualmodus bietet keine KI, auch direkter API-Versuch wird abgewiesen.
- [ ] KI liefert echten Text; Modell-ID, Input/Output, Zeit, erster Entwurf und finaler Text vorhanden.
- [ ] Fehlender Key, Anbieterfehler, Timeout und späte Antwort bleiben als Fehler sichtbar.
- [ ] Refresh erhält Zustand/Zeit; verzögerte Anfrage kann keine andere Runde überschreiben.
- [ ] Nach Abgabe keine Änderung; getrennte Exportpakete enthalten keine Bedingungen/Identitätszuordnung.
- [ ] Zwei Raterdateien lassen sich validieren; unvollständige Bewertungen werden nicht stillschweigend zu 0.

## Organisation

- [ ] Zuständige Person, Teilnahmeinformation, Kontakt und Löschdatum konkretisiert.
- [ ] Schlüssel und Kontakt-/Einladungslisten geschützt; Backup und Abbruchablauf geklärt.
- [ ] Institutionell erforderliche Abstimmungen geklärt.
- [ ] Weniger als 8 erreichbare Personen bis Ende Woche 2 → explorative Fallserie ausdrücklich dokumentieren.
- [ ] Modell, Prompt, Fälle, Rubrik und Analyseplan versioniert/freigegeben, erst dann Freeze.

## Beobachtungsbogen (privat ausfüllen)

Pilot-ID / Datum / Sequenz / Modell / Probleme im Verständnis / Zeiten / Fehler der Oberfläche / Fallunterschiede / Rubrikdifferenzen / technische Abweichungen / Änderungsvorschlag / zuständige Person / erneute Prüfung.

Öffentlich nur bereinigte Erkenntnisse und Entscheidungen dokumentieren, keine ausgefüllten personenbezogenen Bögen. Freigabe bedeutet nicht, dass das Experiment bereits Wirksamkeit bewiesen hat.

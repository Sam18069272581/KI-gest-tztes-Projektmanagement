# 中文使用说明

## 现在已经能做什么

在项目目录运行 `python server.py`，打开 http://127.0.0.1:8874。也可双击 `Start-Lab.cmd`。网页全部使用德语，适合小组演示。

1. 选择四种实验顺序之一，创建 Pilot（试跑）会话。
2. 阅读说明，填写 PM/AI 经验，同意记录；可先打开独立练习。
3. 点击开始后服务器启动 25 分钟倒计时；本轮包含“基础计划”和“风险与变更”两项任务。
4. 输入自动保存，也可点击手动保存。刷新不会重置计时。时间耗尽保留最后及时保存的部分答案。
5. 人工模式没有 AI 按钮，而且服务端也禁止调用。AI 模式保留问题、答案、首份 AI 草稿与人工最终答案。
6. 第一轮提交后休息，再明确点击开始第二轮。最后填写反思，下载自己的记录。

没有 API Key 时，AI 按钮会显示真实的配置错误，不会生成伪造内容。启用方法见主 README。当前版本不声称已经做过真实模型成功调用。

## 周五可以直接拿来讨论

- `docs/01-project/team-roadmap-agenda.md`：德语 Agenda、八人分工、四周路线图。
- `docs/02-research/research-brief.md`：有来源的初步综述与后续检索表。
- `docs/03-experiment/protocol.md`：实验步骤、对照方式和招募条件。
- `docs/03-experiment/scoring-rubric.md`：公开评分规则。具体标准答案另存在本地 researcher-only 文件夹，未上传公开 GitHub。

案例 A/B 都是虚构产品项目。当前故意采用相近结构，降低背景知识差异；同时也存在学习迁移，需要预实验检查并在报告里写清楚。

## 正式实验前必须由团队完成

确认题目和隐私说明；选择可访问的模型快照；做 2–3 人预实验及真实 AI 调用；确认至少 8 人招募目标或改为探索性案例研究；最后运行 Freeze 锁定配置。冻结是团队签署的准备确认，不是软件替你完成了科学验证。

两位评分者各拿一份独立导出包，不能拿到 `private` 映射和原始日志。正式样本和 Pilot 默认分开。时间差使用“AI − 人工”，负值表示本样本中 AI 更快；不能把超时当作快速完成。

当前仅在本机运行。原仓库分支中的实现需要评审后再合并；实际招募、发送邀请、运行实验和最终研究结论不由程序自动完成。



顺序控制：同一轮先完成基础计划并锁定，再显示第二项任务的原计划与变更材料；两项任务共用 25 分钟，避免参考答案提前泄露。

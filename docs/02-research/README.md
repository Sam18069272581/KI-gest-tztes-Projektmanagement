# 02 · Recherche und Wissensbasis

Ziel: eine belastbare Baseline und begründete Einsatzmöglichkeiten der KI erarbeiten, bevor aus einem Tooldemo eine Wirksamkeitsbehauptung wird.

| Schritt | Dokument | Ergebnis |
|---|---|---|
| 1. Überblick | [Recherchebrief](research-brief.md) | Bereits gesichtete Primär-/Herstellerquellen mit Grenzen |
| 2. Gezielt suchen | [Such- und Auswahlprotokoll](search-protocol.md) | Wiederholbare Suche und dokumentierte Auswahl |
| 3. Sammeln | [Literaturregister](literature-register.md) | Eine Quelle pro Zeile, Besitzer und Prüfstatus |
| 4. Prüfen | [Evidenzkarte](evidence/TEMPLATE.md) | Welche Aussage trägt die Quelle wirklich? |
| 5. Synthese | [Baseline, Tools und Risiken](synthesis.md) | Verbindung zwischen Recherche und Messplan |

**Streams:** Marla → PM-Baseline; Tim → KI-Lösungen und Studien; Cara → Chancen/Risiken und Mensch-KI-Zusammenarbeit. Rollen sind zu bestätigende Arbeitsvorschläge.

Eine Quelle wird erst als Kernbeleg genutzt, wenn der relevante Originalabschnitt gelesen wurde. Produktseiten dokumentieren Produktversprechen/Funktionen, keine unabhängige Effektmessung. Kein Upload privater Unternehmensunterlagen oder pauschaler PDF-Sammlungen.
